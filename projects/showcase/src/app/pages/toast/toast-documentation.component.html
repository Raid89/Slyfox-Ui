Toast

The Toast component provides a way to display brief, auto-expiring notifications to the user. It is managed via the ToastService.

Usage

1. Import Animations

Ensure BrowserAnimationsModule is imported in your root application module or provideAnimations (or provideAnimationsAsync) is included in your application config providers.

{{codeExamples.provideAnimations}}

2. Inject ToastService

The ToastContainerComponent is automatically managed by the ToastService. You only need to inject and use the service.

{{codeExamples.usage}}
