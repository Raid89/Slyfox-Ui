Checkbox

A checkbox component that allows users to select multiple options.

Basic Usage


<slf-ui-checkbox [Id]="'unchecked'" [FormControl]="formControl('disable')"></slf-ui-checkbox>
<slf-ui-checkbox [Id]="'unchecked'" [FormControl]="formControl('unchecked')"></slf-ui-checkbox>
<slf-ui-checkbox [Id]="'checked'" [FormControl]="formControl('checked')"></slf-ui-checkbox>

Square Symbol


<slf-ui-checkbox Type="squareSymbol" [Id]="'checked'" [FormControl]="formControl('disable')"></slf-ui-checkbox>
<slf-ui-checkbox Type="squareSymbol" [Id]="'symbolchecked'" [FormControl]="formControl('checked')"></slf-ui-checkbox>

Circle Variants


<slf-ui-checkbox [Id]="'circleunchecked'" Type="circleCheck" [FormControl]="formControl('disable')"></slf-ui-checkbox>
<slf-ui-checkbox [Id]="'circleunchecked'" Type="circleCheck" [FormControl]="formControl('circleUnchecked')"></slf-ui-checkbox>
<slf-ui-checkbox [Id]="'circlechecked'" Type="circleCheck" [FormControl]="formControl('circleChecked')"></slf-ui-checkbox>

Personalización por CSS Variables

Puedes personalizar el Checkbox globalmente, por componente o por instancia usando las siguientes variables CSS:

Variable Valor por defecto Descripción
--checkbox-bg#fffFondo del checkbox
--checkbox-border1px solid var(--border-color-75)Borde
--checkbox-radius4pxRadio del borde
--checkbox-size20pxTamaño del checkbox
--checkbox-colorvar(--primary-color-200)Color del check
--checkbox-bg-checkedvar(--primary-color-200)Fondo cuando está seleccionado
--checkbox-bg-disabledvar(--fill-color-75)Fondo deshabilitado
--checkbox-color-disabledvar(--text-color-100)Color deshabilitado
--checkbox-label-color#36455DColor del label
--checkbox-label-font-size1.6remTamaño fuente label
--checkbox-label-font-weight700Peso fuente label
Ejemplo de personalización por instancia: 
<slf-ui-checkbox style="--checkbox-bg: #f0f0f0; --checkbox-radius: 12px;"></slf-ui-checkbox>
