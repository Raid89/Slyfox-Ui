Personalización por CSS Variables

Puedes personalizar el Toggle globalmente, por componente o por instancia usando las siguientes variables CSS:

Variable Valor por defecto Descripción
--toggle-track-width44pxAncho del track
--toggle-track-height24pxAlto del track
--toggle-radius9999pxRadio del track
--toggle-padding2pxPadding interno
--toggle-bgvar(--secondary-color-75)Fondo inactivo
--toggle-active-bgvar(--primary-color-200)Fondo activo
--toggle-disabled-bgvar(--secondary-color-50)Fondo deshabilitado
--toggle-hover-shadow0px 0px 1px 4px var(--primary-color-100)Sombra hover
--toggle-disabled-shadow0px 0px 0px 0px var(--primary-color-100)Sombra deshabilitado
--toggle-readonly-shadow0px 0px 0px 0px var(--primary-color-100)Sombra solo lectura
--toggle-knob-bg#FFFColor del knob
--toggle-knob-size20pxTamaño del knob
--toggle-knob-radius9999pxRadio del knob
--toggle-label-font-size14pxTamaño fuente label
Ejemplo de personalización por instancia: 
<slf-ui-toggle style="--toggle-active-bg: #00C853; --toggle-knob-size: 28px;"></slf-ui-toggle>
