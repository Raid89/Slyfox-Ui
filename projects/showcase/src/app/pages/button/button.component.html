Button

A versatile button component with different styles and variants.

Basic Usage


<slf-ui-button Text="Primary Button" />
<slf-ui-button Text="Default Button" [IsDisabled]="true" />
<slf-ui-button Text="Loading..." [IsLoading]="true" />

<slf-ui-button Color="secondary" Text="Secondary Button" />
<slf-ui-button Color="secondary" Text="Secondary Button" [IsDisabled]="true" />
<slf-ui-button Color="secondary" Text="Loading..." [IsLoading]="true" />

Personalización por CSS Variables

Puedes personalizar el Button globalmente, por componente o por instancia usando las siguientes variables CSS:

Variable Valor por defecto Descripción
--button-bgvar(--primary-color-200)Fondo principal
--button-bg-hovervar(--primary-color-300)Fondo hover
--button-bg-disabledvar(--fill-color-75)Fondo deshabilitado
--button-color#fffColor de texto
--button-color-disabledvar(--text-color-100)Texto deshabilitado
--button-radius8pxRadio del borde
--button-padding1rem 2.4remPadding
--button-font-size1.6remTamaño de fuente
--button-font-weight700Peso fuente
--button-bordernoneBorde
--button-shadownoneSombra
--button-outlinenoneOutline
Ejemplo de personalización por instancia: 
<slf-ui-button style="--button-bg: #222; --button-radius: 16px;"></slf-ui-button>
